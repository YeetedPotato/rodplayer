# RodPlayer

RodPlayer is a high-quality cross-platform Jellyfin client.

RodPlayer is a standalone Jellyfin-compatible media client. It works with standard Jellyfin servers and Jellyfin-compatible servers.

Phase 1 note: native platform projects are still generated in CI with `flutter create --platforms=...`. Before native playback-engine phases, those projects should be committed so platform-specific source is version-controlled.
